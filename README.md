## О чём репозиторий

Необходимо распараллелить вычислительную задачу с использованием открытых стандартов параллельного программирования на языке C/C++. 

Тема распараллеливания — **умножение квадратных матриц**. В данной лабораторной работе реализована распределённая версия программы с использованием интерфейса передачи сообщений **MPI**. Программа запускается на суперкомпьютере «Сергей Королёв».

## Архитектура

Логика работы с матрицами и вычисления находятся в файлах `main_mpi.cpp` и `matrix_io.h`. Параллелизация выполнена по схеме декомпозиции по строкам: матрица `A` разрезается на горизонтальные полосы и рассылается процессам через `MPI_Scatter`, матрица `B` реплицируется через `MPI_Bcast`, а результат собирается через `MPI_Gather`.

## Методика эксперимента

Замеры времени выполнялись с помощью `MPI_Wtime()` на суперкомпьютере «Сергей Королёв» (узел `login2`, вычислительный узел `n281`). Использовался планировщик SLURM и Intel MPI. Замеры проводились для размеров матриц от 200 до 2000 и числа процессов от 1 до 8.

## Данные

Данные замеров сохранены в файле `results.csv`. Графики зависимостей времени, ускорения и эффективности находятся в папке `img/`.

## Верификация

Корректность вычислений проверяется скриптом `verify.py` (локально, с использованием библиотеки NumPy). Все прогоны успешно прошли проверку (PASS).

## Требования

- Компилятор C++ (GCC 4.8.5 или выше)
- MPI-реализация (Intel MPI 4.1.3)
- Python 3.10+ (для генерации матриц и проверки)
- Python-пакет NumPy (для верификации)

## Быстрый старт

```bash
# Загрузить модуль MPI на кластере
module load intel/mpi4
export I_MPI_CXX=g++

# Скомпилировать программу
mpiicpc -O2 -Wall -std=c++11 -DMPICH_SKIP_MPICXX main_mpi.cpp -o main_mpi

# Запустить через SLURM
sbatch job.sh
